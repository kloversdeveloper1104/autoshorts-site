プライバシーポリシー

最終更新日: 2026年10月22日

取得する情報

AutoShorts は、運営者本人が許可した YouTube / TikTok / Instagram アカウントについて、動画のアップロードに必要な権限と、投稿した動画の統計情報(再生数・高評価数・コメント数・視聴維持率など)のみを取得します。

利用目的

取得した情報は、運営者自身のアカウントへの動画投稿と、動画の改善のための分析にのみ使用します。

保存と共有

認証トークンは運営者が管理する非公開の環境にのみ保存します。取得した情報を第三者に販売・共有することはありません。

Google API から取得した情報の利用は、Google API サービスのユーザーデータに関するポリシー(限定使用の要件を含む)に従います。

アクセスの取り消し

許可はいつでも Google アカウントの権限設定 や各サービスの設定から取り消せます。
